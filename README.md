# Transfer Tracker

### 🔗 [Открыть демо](https://egorkayamzin-byte.github.io/transfer-tracker/)

Дашборд рыночной стоимости футболистов, ленты трансферов и стоимости составов.
Тёмная тема, русский интерфейс, ноль npm-зависимостей.

> Демо — статичная однофайловая сборка с офлайн-срезом данных (см. «Однофайловое превью» ниже).
> Живые данные и полный функционал — только в локальном запуске.

Разделы: **Обзор** · **Рейтинг стоимости** · **Лента трансферов** · **Клубы** · **Лиги** +
карточка игрока с графиком динамики стоимости и историей переходов.

---

## Быстрый старт

### 1. Поднять источник данных

```bash
docker compose up -d
```

Собирает и запускает [`felipeall/transfermarkt-api`](https://github.com/felipeall/transfermarkt-api) —
open-source FastAPI-обёртку над Transfermarkt — на `http://localhost:8000`.
Первая сборка образа занимает пару минут. Проверить: откройте `http://localhost:8000/` — должен
отдаться Swagger.

Без Docker: клонируйте репозиторий обёртки и запустите `poetry install --no-root && python app/main.py`.

### 2. Запустить дашборд

```bash
node server.js
```

Windows: `.\start.ps1` — то же самое плюс автооткрытие браузера.

Нужен **Node.js 18+**. `npm install` не требуется — внешних зависимостей нет.

### 3. Открыть

<http://127.0.0.1:5173>

Сайт открывается **сразу**, на офлайн-срезе, и в фоне подтягивает живые данные.
Полоса под шапкой показывает прогресс сборки; когда она исчезает, а бейдж в шапке
становится зелёным «Live · API» — на экране данные из API.

Первая полная сборка по шести лигам — это ~250 запросов к источнику, порядка 3–7 минут
при `RATE_LIMITING_FREQUENCY=2/3seconds`. Дальше всё берётся из кэша и обновляется раз в час.

## Настройка

Скопируйте `.env.example` → `.env`. Самое полезное:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `TRANSFERMARKT_API_URL` | `http://localhost:8000` | адрес self-hosted API |
| `COMPETITIONS` | `GB1,ES1,IT1,L1,FR1,RU1` | какие лиги отслеживать |
| `CLUBS_PER_COMPETITION` | `20` | клубов из каждой лиги (меньше → быстрее) |
| `TRANSFER_PLAYERS` | `60` | по скольким топ-игрокам строить ленту трансферов |
| `REFRESH_MINUTES` | `60` | период фонового обновления |
| `CACHE_TTL_HOURS` | `6` | сколько живёт кэш ответов апстрима |
| `CONCURRENCY` | `3` | параллельных запросов (выше — быстро словите 429) |

Хотите быстрый первый запуск? Поставьте `COMPETITIONS=GB1` и `CLUBS_PER_COMPETITION=6` —
сборка займёт меньше минуты.

## Как это устроено

```
браузер ──► server.js ──► lib/pipeline.js ──► lib/upstream.js ──► transfermarkt-api ──► Transfermarkt
                │              │                     │
           public/*      агрегация и             очередь, ретраи,
          (весь UI)      нормализация            дисковый кэш
                │              │
           data/seed.json  data/tracking.json
           (офлайн-срез)   (журнал стоимостей)
```

**Почему не ходим в API прямо из браузера.** Апстрим отдаёт «сырые» срезы: список клубов лиги,
состав клуба, профиль игрока. Рейтинга по стоимости и общей ленты трансферов там нет — их надо
собирать из сотен запросов. Сервер делает это один раз, кэширует и отдаёт фронтенду готовый
датасет. Заодно это снимает CORS и не даёт браузеру засыпать источник запросами.

**Журнал стоимостей** (`data/tracking.json`). Апстрим отдаёт только текущую оценку игрока.
Сервер после каждой сборки дописывает изменившиеся значения в журнал — отсюда берётся колонка «Δ»
в рейтинге и блок «Рост стоимости». Поэтому дельты по живым данным появятся не сразу, а после
второго-третьего обновления. Журнал переживает перезапуски; удалить — просто стереть файл.

**Офлайн-срез** (`data/seed.json`). Если API недоступен, сайт показывает его и честно об этом
пишет плашкой. Стоимости, трансферы и суммы составов там реальные (см. «Источники»), актуальны
на 25.08.2026; **помесячная история стоимости в срезе синтезирована** — реальную историю отдаёт
только живой API. Пересобрать срез: `npm run seed` (данные правятся в `scripts/build-seed.js`).

### Однофайловое превью

```bash
npm run preview      # → preview.html
```

Собирает весь интерфейс в один HTML-файл со встроенным офлайн-срезом: открывается двойным
кликом, без Node и без сервера. Фильтры, сортировка, поиск и карточки игроков работают;
живых данных там нет по определению — сетевого слоя в файле не осталось.
Удобно, чтобы показать дашборд кому-то, у кого ничего не установлено.

### API сервера

| Роут | Отдаёт |
|---|---|
| `GET /api/status` | источник, статус сборки, прогресс, счётчики |
| `GET /api/dataset` | весь нормализованный датасет |
| `GET /api/players/:id` | карточка: профиль, история стоимости, трансферы |
| `GET /api/search?q=` | поиск игрока (через апстрим, с локальным фолбэком) |
| `GET /api/refresh` | запустить пересборку (`?force=1` — мимо кэша) |

## Важно про данные и правила

Transfermarkt **не предоставляет публичного API**. `transfermarkt-api` — сторонний open-source
проект, который получает данные скрейпингом, а это противоречит условиям использования
Transfermarkt. Практические следствия:

- Держите `RATE_LIMITING_ENABLE=true` и `CONCURRENCY=3` или ниже. Агрессивные запросы приводят
  к блокировке по IP, после чего API начинает отдавать `500`/`403` — публичный демо-инстанс
  обёртки регулярно лежит именно по этой причине.
- Для личного использования и экспериментов это рабочий вариант. Для публичного сервиса,
  а тем более коммерческого, нужен лицензированный источник — например
  [Sportmonks](https://www.sportmonks.com/) или [API-Football](https://www.api-football.com/):
  у них есть трансферы и статистика по подписке (рыночных оценок Transfermarkt там нет).
- Чтобы перейти на другой источник, достаточно переписать `lib/pipeline.js` — фронтенд знает
  только про формат `/api/dataset` и от апстрима не зависит.

## Структура

```
server.js               HTTP, роутинг, статика, конфиг
lib/upstream.js         клиент API: очередь, ретраи, дисковый кэш
lib/pipeline.js         агрегация в нормализованный датасет, журнал стоимостей
public/index.html       разметка
public/styles.css       тёмная тема, палитра графиков
public/app.js           состояние, роутер, SVG/CSS-графики, все экраны
data/seed.json          офлайн-срез (генерируется)
scripts/build-seed.js   генератор среза
scripts/build-preview.js сборка preview.html — весь UI одним файлом
docker-compose.yml      transfermarkt-api
start.ps1               запуск в Windows
```

Палитра графиков валидирована по правилам доступности: контраст ≥3:1 к поверхности `#141922`,
различимость цветов при дальтонизме (ΔE ≥ 8), диверджентная пара blue↔red с нейтральной осью.
Ни один график не полагается на цвет как единственный канал — везде есть подписи или легенда.
